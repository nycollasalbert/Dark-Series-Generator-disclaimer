## Visao Geral

Este repositorio centraliza as paginas e documentos legais usados pelo **Dark Series Generator**, incluindo Termos de Uso, Politica de Privacidade, Disclaimer e uma pagina inicial simples para navegacao.

O projeto foi montado com uma identidade escura, direta e moderna, usando HTML estatico e documentos Markdown para facilitar hospedagem, revisao e publicacao.

## Arquivos

| Documento | Formato | Descricao |
| --- | --- | --- |
| [WEBSITE_INDEX.html](WEBSITE_INDEX.html) | HTML | Pagina inicial com links para todos os documentos |
| [terms.html](terms.html) | HTML | Versao web dos Termos de Uso |
| [privacy.html](privacy.html) | HTML | Versao web da Politica de Privacidade |
| [disclaimer.html](disclaimer.html) | HTML | Versao web do Disclaimer |
| [TERMS_OF_SERVICE.md](TERMS_OF_SERVICE.md) | Markdown | Termos de Uso em texto editavel |
| [PRIVACY_POLICY.md](PRIVACY_POLICY.md) | Markdown | Politica de Privacidade em texto editavel |
| [DISCLAIMER.md](DISCLAIMER.md) | Markdown | Avisos, limitacoes e responsabilidades |

## Destaques

- Aplicativo desktop local para Windows.
- Processamento principal dos videos no computador do usuario.
- Documentos preparados para fluxos com OAuth, YouTube, Google e TikTok.
- Avisos claros sobre limites de API, cotas, revisoes e responsabilidade do usuario.
- Paginas HTML estaticas, leves e prontas para hospedagem.

> O GitHub nao aplica CSS customizado diretamente no README, por seguranca. Por isso, este arquivo usa Markdown, tabelas e badges para manter um visual bonito dentro do proprio GitHub, enquanto as paginas HTML usam CSS completo.

## Publicacao

Para publicar como site estatico, use o arquivo `WEBSITE_INDEX.html` como pagina inicial ou configure a hospedagem para apontar para ele.

Estrutura recomendada:

```text
/
├── WEBSITE_INDEX.html
├── terms.html
├── privacy.html
├── disclaimer.html
├── TERMS_OF_SERVICE.md
├── PRIVACY_POLICY.md
└── DISCLAIMER.md
```
